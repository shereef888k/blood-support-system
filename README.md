# Blood Support System

## Overview
This project is a real-time blood support system designed to connect blood donors with patients during emergencies. It helps quickly identify suitable donors based on blood group and location, improving response time and saving lives.

## Features
- Register blood donors
- Search donors by blood group
- Emergency request system
- Location-based filtering (basic)
- WhatsApp-based alert concept

## Tech Stack
- JavaScript / Node.js (Backend)
- HTML, CSS (Frontend)
- Database (MongoDB / Firebase if used)

## How it Works
1. Donors register with their details
2. User searches for required blood group
3. System filters matching donors
4. Generates contact / alert (WhatsApp concept)

## Use Case
- Emergency blood requirement
- Community-based donor network
- Quick response during critical situations
